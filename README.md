# SubTrack - Subscription Expense Tracker

A simple website to track your subscriptions (Netflix, Spotify, etc.), see how much you spend, and get reminders before they renew.

## Features
- Add and manage your subscriptions
- See spending analytics
- Get renewal reminders

## Built With
- HTML
- CSS
- JavaScript

## Pages
- index.html - Home page
- subscriptions.html - Your subscriptions
- analytics.html - Spending charts and insights
- reminders.html - Upcoming renewals

## How to Run
1. Download this project
2. Open index.html in your web browser
